## ABOUT

<strong>사용자와 기술 사이의 흐름을 이해하고, 문제가 발생했을 때 원인과 다음 행동을 정리합니다.</strong>

<br />

서비스 기획과 Front-End 개발, 프로젝트 운영을 경험하며  
사용자의 요청이 화면·API·데이터·운영으로 이어지는 흐름을 다뤄왔습니다.

팀장과 PM으로 일정·역할·산출물을 조율하고,  
데이터 운영에서는 반복 오류를 기준화했으며,  
최근에는 Docker 기반 프로젝트를 통해 상태 점검·장애 알림·로그·문서 자동화까지 직접 구성했습니다.

현재는 교육과정을 운영하며  
구성원 간 요청과 변경사항이 실제 운영에 반영되도록 일정과 커뮤니케이션을 조율하고 있습니다.
